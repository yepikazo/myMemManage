Non-Contiguous Memory Allocation

Halaman materi untuk teknik alokasi memori non-contiguous. Di sini dibahas konsep dasar paging, segmentation, dan simulasi page replacement sederhana (FIFO) untuk memperjelas bagaimana frame diisi dan kapan terjadi page fault atau hit.

Pengertian Umum

Non-contiguous allocation adalah teknik penyimpanan memori di mana sebuah proses dapat menempati beberapa blok memori fisik yang tidak berurutan. Untuk mengatasi kebutuhan ruang yang berbeda dan mengurangi eksternal fragmentation, sistem membagi memori menjadi unit tetap yang disebut page dan frame. Address translation dilakukan melalui page table yang memetakan page virtual ke frame fisik; ketika sebuah page tidak terdapat di memori fisik dan dibutuhkan, terjadi page fault dan sistem harus mengambil page dari penyimpanan sekunder atau melakukan penggantian page.

Teknik / Jenis Algoritma

FIFO (First-In, First-Out): Mengganti page yang paling lama berada di memori (yang pertama masuk). Implementasinya sederhana tetapi tidak selalu optimal secara statistik.

LRU (Least Recently Used): Mengganti page yang paling lama tidak digunakan berdasarkan riwayat penggunaan. LRU mendekati keputusan yang baik apabila riwayat akses mencerminkan pola masa depan.

Optimal: (Teoritis) Memilih page yang aksesnya paling lama di masa depan; memberikan jumlah page fault paling sedikit untuk sebuah referensi lengkap, tetapi memerlukan pengetahuan tentang referensi mendatang sehingga biasanya dipakai sebagai acuan bukan untuk implementasi nyata.
